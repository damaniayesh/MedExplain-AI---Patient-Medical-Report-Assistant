# MedExplain-AI - Patient-Medical-Report-Assistant
An AI-powered medical assistant that explains medical terms and uploaded reports in simple, patient-friendly language.

## Objective
To help users understand complex medical reports without needing advanced medical knowledge.

## Steps Followed
1. Imported Python libraries and configured the OpenAI API.
2. Created a system prompt to explain medical information in simple language.
3. Built an AI chatbot to answer medical questions.
4. Created a Gradio interface for the chatbot.
5. Added instructions for different types of medical questions.
6. Implemented PDF and TXT medical report uploads.
7. Extracted text from uploaded medical reports.
8. Sent the extracted text to the AI model for explanation.
9. Displayed the generated explanation in a Gradio interface.
10. Tested the application using a sample orthopedic surgery report.

## Outcome
Successfully built and tested a medical report analyzer that reads uploaded medical reports and generates easy-to-understand explanations.
